# 工程目录与复现说明

本公开仓库只保存能够公开分发的工程快照，不保存运行构建所需的原始商业游戏数据。

## 公开目录

- `汉化补丁/09_release/v38/`：v38 可安装 LayeredFS + ExeFS IPS 文件。
- `CLANNAD外传汉化历史文件/docs/`：状态、安装、署名、统计与历史文档。
- `CLANNAD外传汉化历史文件/scripts/`：关键构建和验证脚本快照。
- `CLANNAD外传汉化历史文件/audit/`：650 条随机抽样及统计摘要。

## 不随仓库提供的输入

复现完整构建需要用户自行从合法持有的对应版本取得：

- 原始 `SCRIPT.PAK`
- 原始 `PARTS.PAK`
- 对应版本的 `main` NSO
- 用户合法持有的 PC 中文补丁输入

仓库不会提供这些原始输入，也不会提供密钥、XCI、NSP 或 NCA。

## 核心技术链

1. 从 PC RealLive 资源恢复 resource/kidoku 与中文记录对应关系。
2. 以 Switch 英文资源作为桥接锚点，将 PC 中文映射到 Switch 正文槽。
3. 对 Switch 拆句/合句与版本差异建立显式规则，不再使用全局顺序猜测。
4. 在固定容量槽内处理文本，最终消除历史截断。
5. 对 LucaSystem `PARTS.PAK` 中确认含英文文字的 CZ3/CZ4 图片做局部中文化并回包。
6. 对主程序可见 UI 字符串建立容量安全的 UTF-8 替换；极短字符串采用已验证的 AArch64 xref 重定位。
7. 执行结构回归、全量子文件哈希对比、IPS 重放、随机统计抽查。

脚本中仍可能保留项目开发机路径作为历史快照；公开仓库不承诺脚本开箱即跑，重点是记录算法和验证方法。
