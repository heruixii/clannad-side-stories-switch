# 安装与测试说明

## 安装

1. 使用与 Title ID `01007B501372C000` 对应的 Nintendo Switch 游戏版本。
2. 从 GitHub Releases 下载 v38-test ZIP。
3. 将 ZIP 中的 `atmosphere/` 复制到 SD 卡根目录并合并。
4. 完全关闭游戏后重新启动。

补丁会覆盖：

- `atmosphere/contents/01007b501372c000/romfs/SCRIPT.PAK`
- `atmosphere/contents/01007b501372c000/romfs/PARTS.PAK`
- `atmosphere/exefs_patches/CLANNAD_Side_Stories_CHS/AB53346DF8D55798AB3304D1712F9966C3999D1D.ips`

## 实机验收重点

当前优先检查严重问题即可：

1. 游戏能否启动且不崩溃。
2. 16 个章节能否进入、推进、结束。
3. 选择项和跳转是否工作。
4. 正文是否出现明显错行/串行。
5. 配置页、系统菜单和主要系统提示是否正常显示中文。
6. 是否出现大面积方框、乱码或字体缺失。

轻微标点、个别措辞、非严重排版问题不影响 v38-test 的当前工程验收结论。

## 回滚

删除本补丁对应的 Title ID 目录和 `CLANNAD_Side_Stories_CHS` ExeFS patch 目录即可撤销 LayeredFS/IPS 修改。游戏本体不会被补丁直接改写。
