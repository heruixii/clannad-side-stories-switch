# CLANNAD Side Stories v38 串行概率统计抽查报告

日期：2026-09-11
对象：v38 正文汉化，共 4573 个正文文本槽
目标：仅判断“严重串行/错行映射”（A 句被写入明显属于 B 句的中文）发生率是否可压到 0.5% 以下。轻微翻译措辞、标点、排版等不计为严重串行。

## 抽样设计

- 总体：4573 个最终正文槽。
- 随机抽样：不放回抽取 650 个槽。
- 固定随机种子：`202609112310`，可复现。
- 章节覆盖：16 个章节均有样本。
- 判断链：优先复核 `Switch 英文 -> PC resource -> CJXHook.dll 中文`；PC 一句被 Switch 拆成多槽的情况按同章节、同 resource 合并后判断；Switch 特有/人工补译槽按上下文检查。
- 统计标准：单侧 95% 置信上限。若 650 个样本中严重串行为 0，则零失效 Clopper-Pearson/二项上限为：

  `p_upper = 1 - 0.05^(1/650) = 0.0045982146 = 0.45982146%`

- 反向检验：如果真实严重串行率恰为 0.5%，650 抽样恰好 0 次命中的概率为：

  `(1 - 0.005)^650 = 0.0384594 = 3.84594%`

  小于 5%，因此在单侧 95% 水平下可以拒绝“严重串行率 >= 0.5%”。

## 抽查结果

- 抽样数：650
- 严重串行：**0**
- 资源链样本：646
- 有可直接比较英文锚点的资源链样本：644
- 英文规范化后完全一致：596
- 第一轮低相似警报：24
  - 其中 23 个在“同 resource 连续槽合并”后相似度 >= 0.90，均为 PC 单句被 Switch 拆句。
  - 剩余 1 个：`Kappei-san, the day has come to face your future.` 对 PC `Kappei-san, today is the day you must face the future.`，中文为“今天是胜平面对未来的一天。”，属于版本措辞改写，不是串行。
- 样本中的无 resource 人工补译：4
  - `That` + 下一槽 `couldn't go out with me.` 合并为一句，中文对应“他不能交往。”，属于切句，不是串行。
  - 其余 3 条均与当前 Switch 英文语义直接对应。
- 样本中的拆句槽：10，按组复核均通过。

## 全体结构辅助检查

除随机样本外，又对 4573 槽的资源顺序做了机械扫描。出现 3 处 resource ID 局部倒退：

1. Episode 4：`197 -> 102`，对应 `Ugh!` 等短感叹词复用；当前英文/中文一致。
2. Episode 10：`80 -> 62`，对应 `Scary!` 等短感叹词复用；当前英文/中文一致。

这些仅作为辅助检查，不计入随机抽样统计。

## 结论

在本报告定义的“严重串行/错行映射”标准下，650 个随机样本中观察到 **0/650** 个严重串行。

这不是数学上证明真实概率绝对小于 0.5%，而是按预先规定的统计置信标准，现有抽查证据已经达到该门槛。
