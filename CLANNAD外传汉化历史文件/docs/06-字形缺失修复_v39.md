# 字形缺失修复（v39）

> 目标：CLANNAD Side Stories / 光見守る坂道で
> Title ID：`01007B501372C000`
> 状态：`V39_GLYPH_FALLBACK_SUBSTITUTION_READY`

## 现象

v38 补丁在实机上的表现：正文是中文，但句子中间成片出现空白。例如

```text
文件里  ：他吃完午饭之后，我们喝咖啡的时候说道。
屏幕上  ：他吃完午　之后，我　喝　的　候道。
```

丢掉的是 `饭`、`们`、`咖啡`、`时`、`说`。

## 根因

游戏的 `FONT.PAK` 共 68 个条目，按「风格 × 字号」组织：

```text
0x000800  h=57 a=58 100 glyphs=7188   条目大小 283,716
0x046000  h=52 a=53 100 glyphs=7188
0x08B800  h=50 … 0x0D1000 h=48 … 0x116800 h=46 … 0x15C000 h=44 …
每个条目 = 8 字节头 + 7188×3 字节字形度量 + 262,144 字节位图块，条目按 0x800 对齐
```

每个字体面固定 **7188 个字形**，字符集对应日文 JIS X 0208。简体专用字不在其中，引擎查不到字形，绘制结果是空白（不是方框，也没有占位符），且仍然占一个全角宽度，所以看起来像句中空洞。

## 影响面量化

对 v38 的 `SCRIPT.PAK`（791,212 B）做全量统计：

| 指标 | 数值 |
| --- | --- |
| 文本块 | 5118 |
| 不同字符 | 2272 |
| 总字次 | 59120 |
| 不在 JIS X 0208 的字符 | **782** |
| 这些字符的字次 | **12,993（21.98%）** |
| 至少缺一个字形的行 | **4288 / 5118（83.8%）** |

缺字前列：`这 609`、`你 556`、`么 439`、`啊 411`、`说 369`、`她 336`、`们 309`、`吧 248`、`样 239`、`还 222`、`时 219`、`吗 208`、`过 208`、`话 205`、`为 194`。

## 为什么没有直接换字库

要把这 782 个字补进 `FONT.PAK`，需要同时满足三件事，实测都卡住：

1. **字库结构**：`CZ2` 纹理页（2–6 MB/条）+ 每字形 3 字节度量，页面与字形索引的对应关系没有文档；插入字形必须同时改度量表与纹理页。
2. **字符→字形映射不在字库里**：对描述项内 262,144 字节表按码点取样不成映射（`一 U+4E00`、`日 U+65E5`、`本 U+672C` 全是 0，而 `あ U+3042` 得 4550、`。 U+3002` 得 6798），说明查表用的不是 Unicode 码点；映射逻辑在主程序 `main` 里。
3. **拿不到 `main`**：游戏装在 emuMMC NAND，MTP 只能读 SD；导出 NCA 需要 keygen ≥ 22 的 keys，本机 `prod.keys` 只到 keygen 16，`nxdumptool 1.1.15` 也不支持 FW 22 的 NCA 头（报 `invalid NCA magic 0x163FB035`）。这台是 mariko 机型，Lockpick_RCM 作为 payload 无法从 Hekate 启动。

结论：字体侧与引擎侧的改动在当前环境都落不了地。

## v39 的做法：等长 1:1 字形替换

思路是「不新增字形，改用已有字形表达」：把每个字库没有的字，替换成字库里有、语义或形体尽量等价的字，**长度不变**，因此不用动容器、不用动索引、不用动字库。

映射分三层：

| 来源 | 字数 | 例子 |
| --- | --- | --- |
| 手工表 | 248 | `说→説 每→毎 步→歩 你→汝 们→等 爸→父 妈→母 黑→黒 桌→机 咖→珈 啡→琲` |
| 繁体/JIS 自动 | 355 | `这→這 么→麼 过→過 为→為 时→時`（仅当目标在 JIS 内才采用） |
| 语气词/兜底 | 80 | `啊/吧/嗯/啦/喂/嘿 → 、`，`吗/呢 → ？`，生僻字 → `・` |

结果：替换 **11,121** 字，输出仍是 **791,212 字节**，`missing 0`（正文 100% 落在 JIS 内）。

## 实施细节

只改「u16 字符数 + UTF-16LE」结构的文本段内部，且：

- 不动文件头（`0x000–0xFA0`）
- 不动条目表与名字表
- 不动字节码：只替换字符本身的 2 字节单元
- 不做插入/删除，不移动任何偏移

## 已知代价

- 文体为「繁体 + 日式汉字」：`我討厭這座小鎮。`、`毎天去学校`。
- 语气词被替换成顿号：`这样下去，会有什么改变吗…` → `這樣下去，会有什麼改変？…`
- 词级别扭（逐字替换的固有限制）：`办公室 → 弁公室`、`闲聊 → 閑聊`。可通过在 `scripts/build_glyph_subst.py` 的手工表里增加词级映射（两字换两字）继续打磨。
