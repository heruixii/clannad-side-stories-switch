# CLANNAD Side Stories 简中 · v39-test（字形修复版）

> Title ID：`01007B501372C000`（**CLANNAD Side Stories / 光見守る坂道で / 外传**）
> 注意：`0100A3A00CC7E000` 是**正传 CLANNAD**，两个 Title ID 不要混用。
> 状态标记：`V39_GLYPH_FALLBACK_SUBSTITUTION_READY`

## 这一版解决什么

v38 的核心问题是：正文虽然全部汉化，但游戏自带的 `FONT.PAK` 每个字体面只有 **7188 个字形**，字符集是日文（JIS X 0208）。简体字里凡是不在 JIS 里的（这、说、时、们、你、她、吧、吗、嗯……）在实机上没有字形，渲染结果是**空白**，表现为句子中间一个个空洞。

实测数据（v38 的 `SCRIPT.PAK`，5118 个文本块 / 2272 个不同字符 / 59120 个字次）：

| 指标 | 数值 |
| --- | --- |
| 不在 JIS X 0208 的字符 | **782 个** |
| 这些字符的出现次数 | **12,993 次（21.98%）** |
| 至少缺一个字形的行 | **4288 / 5118（83.8%）** |

v38 文档里「原游戏字库具备所需 CJK 覆盖」的结论与实机不符：覆盖的是 JIS，不含简体专用字。

## 这一版怎么修的

不改字库、不改主程序、不改容器结构，只做**等长 1:1 字形替换**：把每个字库没有的简体字，换成字库里确实存在、且语义/形体尽量等价的字。

- 手工映射 **248** 字（`说→説 每→毎 步→歩 你→汝 们→等 爸→父 妈→母 黑→黒 桌→机 咖→珈 啡→琲 …`）
- 繁体/JIS 自动映射 **355** 字（`这→這 么→麼 过→過 为→為 时→時 …`，仅当目标字在 JIS 内才采用）
- 语气词归并到顿号/问号：`啊/吧/嗯/啦/喂/嘿 → 、`，`吗/呢 → ？`
- 极少数生僻字/拟声词落 **`・`**（80 字）

合计替换 **11,121** 个字，`SCRIPT.PAK` 长度保持 **791,212 字节**不变，容器头、条目表、名字表、字节码、其他 PAK 全部未动。

替换后正文的字符 **100% 落在 JIS X 0208 内**，实机不再出现空白字。

## 安装

1. 确认游戏 Title ID 为 `01007B501372C000`。
2. 把本目录里的 `atmosphere/` 复制到 SD 卡根目录并合并。
3. **完全退出游戏**后重新启动（Home → X → 关闭，或重启机器）。

目录结构：

```text
atmosphere/
└─ contents/
   └─ 01007B501372C000/
      └─ romfs/
         └─ SCRIPT.PAK
```

这一版只覆盖 `SCRIPT.PAK`。若要保留 v38 的菜单/UI 图片汉化（`PARTS.PAK`）与 ExeFS 字符串补丁，把 v38 包里对应文件一起装上即可，两者互不冲突：v39 的 `SCRIPT.PAK` 与 v38 的 `PARTS.PAK` / IPS 可以共存。

## 从 v38 升级：先卸载旧补丁，再装新补丁

v38 与 v39 覆盖同一个文件 `SCRIPT.PAK`，按下面三步做，能保证回到干净状态。

**第一步：卸载旧补丁（v38）**

```text
SD:/atmosphere/contents/01007b501372c000/                 ← 整个目录删掉
SD:/atmosphere/exefs_patches/CLANNAD_Side_Stories_CHS/    ← 整个目录删掉（装过 v38 的 ExeFS IPS 才需要）
```

只想保留 v38 的 UI 图片汉化时，可以只删一个文件：

```text
SD:/atmosphere/contents/01007b501372c000/romfs/SCRIPT.PAK
```

（`PARTS.PAK` 与 v39 的 `SCRIPT.PAK` 可以共存。）

**第二步：安装 v39**

```text
1) 解压 CLANNAD_Side_Stories_CHS_v39_glyphfix.zip
2) 把 atmosphere 文件夹整体复制到 SD 卡根目录，选择「合并 / 覆盖」
3) 核对：
   SD:/atmosphere/contents/01007B501372C000/romfs/SCRIPT.PAK     791,212 字节
4) 完全退出游戏（Home → 光标停在游戏上 → X → 关闭），或直接重启机器
```

**第三步：验收**

```text
✔ 首句显示「今早，我成為了一名三年級学生。」 → v39 生效
✘ 仍是日文假名 → 没读到补丁：Title ID 目录名不对 / 目录层级错 / 游戏没完全退出
✘ 仍有空白字 → 装的还是 v38 的 SCRIPT.PAK，核对上面的字节数
```

**退回 v38**：删掉 v39 的 `SCRIPT.PAK`，把 v38 包里的同名文件放回原位。

## 卸载 / 回滚

删除 `SD:/atmosphere/contents/01007B501372C000` 整个目录即可（如果之前装过 v38，这个目录里原本就有 v38 的 `SCRIPT.PAK` 和 `PARTS.PAK`，卸载前建议先备份）。游戏本体不会被修改。

## 已知代价

- 文体变成「繁体 + 日式汉字」，例如 `我討厭這座小鎮。`、`毎天去学校`。
- 语气词被替换成顿号，`这样下去，会有什么改变吗…` 会显示为 `這樣下去，会有什麼改変？…`。
- 少数词级别扭，因为只能逐字替换：`办公室 → 弁公室`、`闲聊 → 閑聊`。这类问题可以在 `scripts/build_glyph_subst.py` 的手工表里补词级映射（两字换两字，长度不变）。
